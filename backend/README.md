# SYMMETROLOGY.ORG — собственный приём заявок

Эта папка содержит `Code.gs`: сервер Google Apps Script для формы **Request Access**.
Письма направляются на **nextdollmill@gmail.com**. Каждая принятая заявка записывается в приватную Google Таблицу `SYMMETROLOGY — Requests`; уведомление в Gmail — дополнительный канал, а не единственное хранилище.

**Статус: код подготовлен и локально протестирован. Он НЕ подключён к действующему сайту до получения адреса реального веб-приложения `.../exec` и проверки доставки.**

## Что требуется владельцу — один раз

1. Откройте **https://script.google.com/home/projects/create** в Google-аккаунте **nextdollmill@gmail.com**.
2. Назовите проект `SYMMETROLOGY — Requests`; замените содержимое файла `Code.gs` кодом из [backend/Code.gs](Code.gs); сохраните.
3. Выберите сверху функцию **setup** → **Выполнить / Run** → разрешите доступ к Google Таблицам и отправке почты. Функция создаст таблицу и напечатает её ссылку в Execution log.
4. Выберите **testDelivery** → **Выполнить / Run**. Проверьте: в таблице появилась строка с типом `owner_delivery_test_...` и статусом **SENT**; в Gmail есть сообщение **[SYMMETROLOGY] New request** (проверьте «Входящие», «Отправленные» и «Спам»). Если статус EMAIL_ERROR, проверьте Execution log и доступ к MailApp.
5. **Развернуть → Новое развёртывание → Веб-приложение / Deploy → New deployment → Web app**. 
   - Execute as / От имени: **Me / Меня**
   - Who has access / Доступ: **Anyone / Все**
   - Нажмите **Deploy**, скопируйте **Web app URL**, заканчивающийся **/exec**.
6. Передайте только этот публичный URL `/exec` в чат. **Не присылайте пароль, токены и секреты.** После этого проверим общедоступный endpoint, переключим форму с FormSubmit на новый `action`, отправим одну контрольную заявку с опубликованной страницы и проверим обе копии: запись в таблице и письмо.

## Как будет работать форма

GitHub Pages (статический сайт) отправляет обычную форму методом **POST** прямо на `/exec`. Backend сохраняет запись, пытается отправить письмо на нужный Gmail и выводит пользователю страницу подтверждения с уникальным номером. Если отправка письма сломалась, запись остаётся в таблице; статус в ней — `EMAIL_ERROR`. Если таблица не принимает запись, вместо ложного подтверждения показывается ошибка и прямой контакт.

Обычная HTML-отправка выбрана сознательно: Google Apps Script не даёт универсального CORS API для надёжного `fetch` из GitHub Pages. Поэтому посетитель после отправки временно увидит подтверждение на странице Google с кнопкой возврата на сайт.

**Защита:** проверка email, скрытое поле-ловушка, предотвращение повторной отправки за 90 секунд, блокировка конкурентной записи, нейтрализация формул Google Sheets. Для высокой нагрузки можно добавить CAPTCHA, мониторинг и отдельный почтовый сервис; квота MailApp бесплатного Gmail сейчас обычно ограничена примерно 100 получателями в сутки (может меняться). Сохранение заявок остаётся приоритетным.

**Важно:** `setup()` и `testDelivery()` нужно выполнить из редактора именно под аккаунтом, которому будет принадлежать таблица. Не включайте новую форму на основном сайте до успешного теста.

Официальная документация: https://developers.google.com/apps-script/guides/web и https://developers.google.com/apps-script/guides/services/quotas
